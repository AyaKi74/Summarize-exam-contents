ประมวลจริยธรรม = {
    จัดทำโดย "องค์กรกลางบริหารงานบุคคล" ของเจ้าหน้าที่รัฐแต่ละประเภท 
    (เช่น ก.พ., ก.ค.ศ., ก.ถ., ก.ตร.) เพื่อใช้เป็นเกณฑ์ปฏิบัติตน

    ถ้าไม่มีองค์กรกลางบริหารงานบุคคล ให้คณะรัฐมนตรีเป็นผู้จัดทำ
}

มาตรา 3 {
    หน่วยงานของรัฐ = {
        กระทรวง ทบวง กรม ส่วนราชการที่เรียกชื่ออื่นและมีฐานะเป็นกรม
        ราชการท้องถิ่น รัฐวิสาหกิจ องค์การมหาชน หรือหน่วยงานอื่นของรัฐในฝ่ายบริหาร

        (ไม่รวมถึง : หน่วยงานธุรการของรัฐสภา องค์กรอิสระ ศาล และองค์กรอัยการ)
    }

    เจ้าหน้าที่ของรัฐ = {
        ข้าราชการ พนักงาน ลูกจ้าง หรือผู้ปฏิบัติงานอื่นในหน่วยงานของรัฐ
    }

    องค์กรกลางบริหารงานบุคคล = {
        1. คณะกรรมการข้าราชการพลเรือน (ก.พ.)
        2. คณะกรรมการข้าราชการพลเรือนในสถาบันอุดมศึกษา (ก.พ.อ.)
        3. คณะกรรมการข้าราชการครูและบุคลากรทางการศึกษา (ก.ค.ศ.)
        4. คณะกรรมการข้าราชการตำรวจ (ก.ตร.)
        5. คณะกรรมการกลางบริหารงานบุคคลของเจ้าหน้าที่ของรัฐในฝ่ายบริหาร
        6. คณะกรรมการมาตรฐานการบริหารงานบุคคลส่วนท้องถิ่น (ก.ถ.)
    }

    กรรมการ = {
        กรรมการมาตรฐานทางจริยธรรม (ก.ม.จ.)
    }
}

มาตรา 4 ผู้รักษาการตาม พรบ. นี้ = {
    นายกรัฐมนตรี
}

หมวด 1 มาตรฐานทางจริยธรรมและประมวลจริยธรรม
{
    มาตรา 5 มาตรฐานทางจริยธรรม 7 ประการ = {
        1. ยึดมั่นในสถาบันหลักของประเทศ (ชาติ ศาสนา พระมหากษัตริย์ และการปกครองระบอบประชาธิปไตยฯ)
        2. ซื่อสัตย์สุจริต มีจิตสำนึกที่ดี และรับผิดชอบต่อหน้าที่
        3. กล้าตัดสินใจและกระทำในสิ่งที่ถูกต้องชอบธรรม
        4. คิดถึงประโยชน์ส่วนรวมมากกว่าประโยชน์ส่วนตน และมีจิตสาธารณะ
        5. มุ่งผลสัมฤทธิ์ของงาน
        6. ปฏิบัติหน้าที่อย่างเป็นธรรมและไม่เลือกปฏิบัติ
        7. ดำรงตนเป็นแบบอย่างที่ดีและรักษาภาพลักษณ์ของทางราชการ
        
        [สูตรจำ: มั่น - ซื่อ - ตัด - รวม - สัม - ธรรม - ดี]
    }

    มาตรา 6 ให้องค์กรกลางบริหารงานบุคคลจัดทำ "ประมวลจริยธรรม" สำหรับเจ้าหน้าที่ของรัฐในความรับผิดชอบ
    (หากหน่วยงานใดไม่มีองค์กรกลางบริหารงานบุคคล ให้ คณะรัฐมนตรี (ครม.) เป็นผู้จัดทำ)
}

หมวด 2 คณะกรรมการมาตรฐานทางจริยธรรม (ก.ม.จ.)
{
    มาตรา 8 องค์ประกอบของ ก.ม.จ. {
        1. ประธานกรรมการ = นายกรัฐมนตรี หรือรองนายกรัฐมนตรีที่นายกรัฐมนตรีมอบหมาย
        2. รองประธานกรรมการ = ผู้แทน ก.พ. ที่ได้รับมอบหมาย
        3. กรรมการโดยตำแหน่ง (5 คน) = ผู้แทนจาก [ก.พ.อ. / ก.ค.ศ. / ก.ตร. / ก.ถ. / สภากลาโหม]
        4. กรรมการผู้ทรงคุณวุฒิ = นายกรัฐมนตรีแต่งตั้ง ไม่เกิน 5 คน
        5. กรรมการและเลขานุการ = เลขาธิการ ก.พ.
        (ผู้ช่วยเลขานุการ = ข้าราชการในสำนักงาน ก.พ. แต่งตั้งโดยเลขาธิการ ก.พ.)

        [รวมทั้งหมด ไม่เกิน 13 คน]
    }

    มาตรา 9 ผู้ทรงคุณวุฒิ ต้องมีความรู้/ประสบการณ์ด้าน {
        การส่งเสริมจริยธรรม, กฎหมาย, การบริหารงานบุคคล, การพัฒนาทรัพยากรมนุษย์
    }

    มาตรา 10 วาระการดำรงตำแหน่งผู้ทรงคุณวุฒิ = {
        คราวละ 3 ปี (แต่งตั้งใหม่อีกได้ แต่ห้ามดำรงตำแหน่งติดต่อกันเกิน 2 วาระ)
    }

    มาตรา 13 หน้าที่และอำนาจสำคัญของ ก.ม.จ. {
        - เสนอแนะนโยบาย/ยุทธศาสตร์ด้านจริยธรรมต่อ ครม.
        - กำหนดแนวทาง/มาตรฐานในการขับเคลื่อนและประเมินผล
        - ตรวจสอบรายงานประจำปีของหน่วยงานรัฐ แล้วเสนอ ครม. อย่างน้อยปีละ 1 ครั้ง
        - ตีความและวินิจฉัยปัญหาที่เกิดจากการบังคับใช้ พรบ. นี้
    }
}

หมวด 3 การรักษาจริยธรรมของเจ้าหน้าที่ของรัฐ
{
    มาตรา 19 หน่วยงานของรัฐต้อง {
        - จัดให้มีผู้รับผิดชอบเกี่ยวกับการรักษาจริยธรรมประจำหน่วยงาน
        - จัดกิจกรรมส่งเสริม อบรม และประเมินผล
        - ทำรายงานประจำปีเสนอต่อ ก.ม.จ. ทุกสิ้นปีงบประมาณ
    }

    มาตรา 20 องค์กรกลางบริหารงานบุคคลต้อง {
        - กำกับดูแลกระบวนการรักษาจริยธรรม
        - จัดทำหลักสูตรฝึกอบรม
        - กำหนดมาตรการจูงใจ (เช่น การยกย่องเชิดชูเกียรติเจ้าหน้าที่ที่เป็นแบบอย่างที่ดี)
    }

หัวใจของรัฐธรรมนูธ คือ 
{
	หมวดที่ 3 สิทธิและเสรีภาพของชาวไทย
}

หมวดที่ 1  หมวดบททั่วไป
{
	มาตราที่ 1 : ประเทศไทยเป็นอันหนึ่งอันเดียว แบ่งภาคได้ แต่แบ่งรัฐ ไม่ได้
	
	มาตราที่ 3 : อำนาจเป็นของประชาชน
	แต่king สามารถใช้อำนาจได้ 3 ทาง คือ รัฐสภา(ออกกฎมาย) , คณะรัฐมนตรี(บริหารประเทศ) ,
	ศาล(ให้ความยุติธรรม)

	มาตราที่ 4 : ว่าด้วยศักดิ์ศรีความเป็นมนุษย์ สิทธิและเสรีภาพ ความเสมอภาคของบุคคล

	มาตราที่ 5 : รัฐธรรมนูธเป็นกฏหมายสูงสุดของประเทศ
}

หมวดที่ 3 สิทธิ และ เสรีภาพ
{
	มาตราที่ 27 : คนเท่ากันในกฎหมาย ชายหญิงเท่าเทียมกัน
	
	มาตราที่ 28 : คนมีสิทธิในชีวิติตัวเอง แต่ห้ามเบียดเบียนคนอื่น เว้นแต่จะมีคำสั่งศาล

	มาตราที่ 48 : แม่ที่ท้อง(ก่อนและหลังคลอด) จะได้รับความคุ้มครองและช่วยเหลือตามกฏหมายกำหนด และ ใครที่มีอายุเกิน 16 ปีและคนยากไร้ ไม่มีรายได้ที่พอต่อการมีชีวิต มีสิทธิ์ได้รับการช่วยเหลือจากรัฐ

}


หมวดที่ 4 หน้าที่ของคนไทย (บังคับคนทั่วไป)
{
	มาตราที่ 50 : คนไทยมีหน้าที่
	{
		1. เข้ารับการศึกษาในการศึกษาภาคบังคับ ( 9ปี ประถม + ม.ต้น) ,
		2. ผู้ชายต้องรับราชการทหาร ,
		3. ไปใช้สิทธิเลือกตั้งหรือลงประชามติอย่างอิสระ โดยนึกถึงผลประโยชน์ต่อประเทศ ,
		4.รักษาสิ่งแวดล้อม ทรัพยากรธรรมชาติ และ ความหลากหลายทางชีวภาพ และ มรดกทางวัฒนธรรม,
		5.ไม่สนับสนุนการโกงทุกรูปแบบ
	}	
}


หมวดที่ 5 หน้าที่ของรัฐ
{
	มาตราที่ 54 : รัฐต้องจัดให้เด็กทุกคนได้เรียน เป็นเวลา 12 ปี ตั้งแต่ก่อนวัยเรียน จนจบการศึกษาภาคบังคับอย่างมีคุณภาพและฟรี (3ก่อนประถม+ 9ภาคบังคับ) ,
	รัฐต้องจัดการให้เด็กเล็กได้รับการดูแลและการพัฒนาก่อนเข้าเรียน เพื่อพัฒนา กาย ใจ วินับ อารมณ์ สังคม และ สติปัญญา ให้สมวัย ( 6 ด้าน ),
	ตั้งกองทุน กสศ.(กองทุนเพื่อความเสมอภาคทางการศึกษา)
}

{

		ประธานวุฒิสภา = รองประธานสภา, 
		if ไม่มีประธานสภาผู้แทน หรือ ประธานสภาผู้แทน ไม่อยู่ หรือ ไม่สามารถปฏิบัติหน้าที่ได้ {

	}
	ส่วนที่ 2 สภาผู้แทนราษฎร {
		มาตราที่ 95 : คนที่มีคุณสมบัติตามนี้ มีสิทธิ์เลือกตั้ง{
			1. มีสัญชาติไทย ถ้าแปลงสัญชาติต้องได้รับสัญชาติมาไม่ร้อยกว่า 5 ปี
			2. มีอายุไม่ต่ำกว่า 18 ปี ในวันเลือกตั้ง
			3. มีชื่ออยู่ในทะเบียนบ้านในเขตเลือกตั้ง ไม่น้อยกว่า 90 วัน นับถึงวันเลือกตั้ง
		}

		มาตราที่ 96 คนที่มีลักษณะแบบนี้ในวันเลือกตั้ง เป็นคนที่ห้ามไม่ให้ใช้สิทธิ์เลือกตั้ง{
			1. เป็นพระภิกษุ สารเณร นักพรต หรือ นักบวช
			2. อยู่ในระหว่างถูกเพิกถอนสิทธิ์เลือกตั้ง  
			3. ต้องคุมขังอยู่โดยหมายศาล
			4. วิกลจริตหรือจิตพั่นเฟืองไม่สมประกอบ

			[แม่ชี, ผีบ้า, ขี้คุก, เพิกถอน]
		}
		
		มาตราที่ 97 คนที่มีคุณสมบัติตามนี้ เป็นผู้มีสิทธิ์สมัครรับเลือกตั้ง เป็นสมาชิกสภาผู้แทนราษฎร{
			1. มีสัญชาติไทยโดยกำเนิด
			2. มีอายุไม่ต่ำกว่า 25 ปี นับถึงวันเลือกตั้ง 
			3. เป็นสมาชิกพรรคการเมือง เป็นเวลาไม่น้อยกว่า 90 วันนับถึงวันเลือกตั้ง 
			เว้นแต่ในกรณีที่มีการเลือกตั้งทั่วไป เพราะเหตุยุบสภา เวลาจะลดเหลือ 30 วัน
		}

		ยุบสภา ต้องจัดการเลือกตั้งซ่อม ไม่น้อยกว่า 45 วัน แต่ไม่เกิน 60 วัน

		มาตราที่ 99 อายุของสภาผู้แทนราษฎร{

		}

		มาตราที่ 100 สมาชิกภาพของสมาชิกสภาผู้แทนราษฎร{

		}

			ถ้าอายุของสภาผู้แทน.หมด king จะประทับตรา พรฎ. ให้เลือกตั้งสส.ใหม่ 
			เป็นการเลือกตั้งทั่วไป ภายใน 45 วัน นับตั้งแต่วันที่สส. หมดอายุ
		}

			นับตั้งแต่วันที่พรฎ.บังคับใช้

หมวดที่ 8 คณะรัฐมนตรี 
{
	มาตราที่ 158 {
		king แต่งตั้งนายก และ รัฐมนตรีอื่น จำนวน{
			นายก 1 คน และ รัฐมนตรีอื่น ไม่เกิน 35 คน
		} ประกอบเป็นคณะรัฐมนตรี
	}

	มาตราที่ 160 รัฐมนตรีต้อง{
		1. มีสัญชาติไทยตั้งแต่เกิด
		2. ไม่อายุไม่ต่ำกว่า 35 ปี
		3. วุฒิการศึกษาไม่ต่ำกว่าป.ตรีหรือเทียบเท่า
		4. มีความซื่อสัตย์สุจริตเป็นที่เห็นชัด
		5. ไม่มีพฤติกรรมที่เป็นการฝ่าฝืนหรือไม่ปฏิบัติตามมาตราฐานทางจริยธรรมอย่างร้ายแรง
		6. ไม่มีลักษณะต้องห้ามตามมาตรา 98
		7. ไม่เป็นผู้มีหมายให้จำคุก ถึงคดีนั้นจะยังไม่ถึงที่สุดหรือมีการ รอ การลงโทษ เว้นแต่ในความผิดที่กระทำโดยประมาท ความผิดลหุโทษ หรือความผิดฐานหมื่นประมาท
		8. ไม่เป็นผู้เคยพ้นจากตำแหน่ง เพราะเหตุกระทำที่เป็นการต้องห้าม ตามมาตราที่ 186 หรือ มาตราที่ 187 มาแล้วยังไม่ถึง 2 ปี นับตั้งแต่วันแต่งตั้ง
	}

	ประธานรัฐมนตรี รับใช้ King และ รัฐมนตรี 1 คน สามารถควบหลายกระทรวงได้
	คณะรัฐมนตรี มีไม่เกิน 36 คน ( นายก + รัฐมนตรีอื่น 35 คน )

	King เป็นคนแต่งตั้ง และ ให้นายกเป็นผู้ลงนาม
}

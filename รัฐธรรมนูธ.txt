รัฐธรรมนูธ{
	หมวด : 15
	บทเฉพาะกาล : 1
	มาตราที่ : 279
}

หัวใจของรัฐธรรมนูธ คือ หมวดที่ 3 สิทธิและเสรีภาพของชาวไทย


หมวดที่ 1  หมวดบททั่วไป
{
	มาตราที่ 1 : ประเทศไทยเป็นอันหนึ่งอันเดียว แบ่งภาคได้ แต่แบ่งรัฐ ไม่ได้
	
	มาตราที่ 3 : อำนาจเป็นของประชาชน
	แต่king สามารถใช้อำนาจได้ 3 ทาง คือ รัฐสภา(ออกกฎมาย) , คณะรัฐมนตรี(บริหารประเทศ) ,
	ศาล(ให้ความยุติธรรม)

	มาตราที่ 4 : ว่าด้วยศักดิ์ศรีความเป็นมนุษย์ สิทธิและเสรีภาพ ความเสมอภาคของบุคคล

	มาตราที่ 5 : รัฐธรรมนูธเป็นกฏหมายสูงสุดของประเทศ
}

{

	มาตราที่ 10 : king can แต่งตั้งผู้ทรงคุณวุฒิ {
	ประธาน 1 คน , องคมนตรีอื่นๆ ไม่เกิน 18 คน }

}

หมวดที่ 3 สิทธิ และ เสรีภาพ
{
	มาตราที่ 27 : คนเท่ากันในกฎหมาย ชายหญิงเท่าเทียมกัน
	
	มาตราที่ 28 : คนมีสิทธิในชีวิติตัวเอง แต่ห้ามเบียดเบียนคนอื่น เว้นแต่จะมีคำสั่งศาล

	มาตราที่ 48 : แม่ที่ท้อง(ก่อนและหลังคลอด) จะได้รับความคุ้มครองและช่วยเหลือตามกฏหมายกำหนด และ ใครที่มีอายุเกิน 16 ปีและคนยากไร้ ไม่มีรายได้ที่พอต่อการมีชีวิต มีสิทธิ์ได้รับการช่วยเหลือจากรัฐ

}


หมวดที่ 4 หน้าที่ของคนไทย (บังคับคนทั่วไป)
{
	มาตราที่ 50 : คนไทยมีหน้าที่{
	เข้ารับการศึกษาในการศึกษาภาคบังคับ ( 9ปี ประถม + ม.ต้น) ,
	ผู้ชายต้องรับราชการทหาร ,
	ไปใช้สิทธิเลือกตั้งหรือลงประชามติอย่างอิสระ โดยนึกถึงผลประโยชน์ต่อประเทศ ,
	รักษาสิ่งแวดล้อม ทรัพยากรธรรมชาติ และ ความหลากหลายทางชีวภาพ และ มรดกทางวัฒนธรรม,
	ไม่สนับสนุนการโกงทุกรูปแบบ
	}	
}









หมวดที่ 5 หน้าที่ของรัฐ
{
	มาตราที่ 54 : รัฐต้องจัดให้เด็กทุกคนได้เรียน เป็นเวลา 12 ปี ตั้งแต่ก่อนวัยเรียน จนจบการศึกษาภาคบังคับอย่างมีคุณภาพและฟรี (3ก่อนประถม+ 9ภาคบังคับ) ,
	รัฐต้องจัดการให้เด็กเล็กได้รับการดูแลและการพัฒนาก่อนเข้าเรียน เพื่อพัฒนา กาย ใจ วินับ อารมณ์ สังคม และ สติปัญญา ให้สมวัย ( 6 ด้าน ),
	ตั้งกองทุน กคศ.(กองทุนเพื่อความเสมอภาคทางการศึกษา)
}
